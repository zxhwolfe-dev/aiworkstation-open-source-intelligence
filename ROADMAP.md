## Hosted MCP

- [ ] Select canonical public MCP hostname
- [ ] Deploy behind authenticated TLS gateway or native authorization
- [ ] Per-user identity / OAuth where required
- [ ] Revocation and scope model
- [ ] Quotas, rate limits, and abuse controls
- [ ] Production monitoring and incident response
- [ ] Service-specific privacy/terms URLs and retention policy
- [ ] Remote bilingual MCP smoke tests
- [ ] Register hosted MCP connection with target platforms
- [ ] Publish to the MCP Registry when the endpoint/package satisfies registry requirements

## Product expansion

Potential future work is driven by external-alpha evidence rather than by feature count:

- richer project and category exploration;
- saved research and alerts;
- evidence freshness views;
- project change history;
- enterprise evaluation packs;
- additional read-only research tools;
- carefully scoped authenticated workflows.

Write-capable tools, third-party repository execution, and unrestricted public hosting are intentionally outside the current product boundary.
