# Code of Conduct

## Our standard

We want this project to be a useful, technically rigorous, and welcoming place for people researching and building with open-source AI.

Examples of behavior that contributes to a positive environment include:

- communicating with technical clarity and respect;
- criticizing ideas and code rather than people;
- distinguishing verified evidence from opinion;
- acknowledging uncertainty and correcting mistakes promptly;
- respecting privacy, licenses, security boundaries, and third-party rights;
- helping new contributors reproduce issues safely.

Unacceptable behavior includes harassment, discriminatory or threatening conduct, deliberate disclosure of private information, posting real credentials or confidential data, weaponizing security reports, or repeatedly misrepresenting unverified claims as verified project facts.

## Scope

This code applies in repository issues, pull requests, discussions, reviews, project-managed community spaces, and other public interactions where a participant represents the project.

## Enforcement

Project maintainers may edit, hide, lock, or remove contributions that violate this code and may temporarily or permanently restrict participation when necessary to protect the community or project.

For ordinary moderation concerns, contact the maintainers through the support path in [`SUPPORT.md`](SUPPORT.md). Security-sensitive or privacy-sensitive concerns should follow [`SECURITY.md`](SECURITY.md) rather than being posted publicly.

## Attribution

This code is inspired by the principles of the Contributor Covenant and adapted to the project's evidence, privacy, and security requirements.
