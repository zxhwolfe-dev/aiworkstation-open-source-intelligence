# Privacy Statement

## Current repository behavior

The M0 code in this repository runs locally with deterministic fixture data. It
does not provide a hosted service, create accounts, set cookies, upload files or
send tool requests to AI Workstation or any third party.

GitHub itself may process repository visits, clones, issues and other platform
activity under GitHub's own terms and privacy practices.

## Planned production behavior

Before a hosted MCP or API endpoint is made public, the product will publish a
service-specific privacy policy covering:

- data categories and purposes;
- legal basis where applicable;
- processors and hosting regions;
- retention and deletion periods;
- security controls;
- user access, export, correction and deletion channels;
- whether submitted data is used for model training;
- international transfers and applicable safeguards.

## Data-minimization rule

The planned tools require technical requirements and public project identifiers.
Users should not submit credentials, customer documents, proprietary source code,
personal data or other confidential information. Production logging must avoid
storing complete prompts by default and must never store secrets intentionally.
