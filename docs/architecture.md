# Architecture

## Goal

Convert AI Open Source Radar capabilities into reusable distribution components.

## Layers

```
User
 |
Skills
 |
MCP tools
 |
API adapters
 |
AI Workstation / akaiagents backend
 |
Validated project intelligence
```

## First Skills

### open-source-project-research

Find and verify open-source AI projects from user requirements.

### open-source-project-comparison

Compare projects, alternatives and trade-offs.

### open-source-stack-planner

Compose practical AI technology stacks from verified projects.

## First MCP tools

- search_ai_projects
- get_project_facts
- get_license_evidence
- compare_ai_projects
- find_alternatives
- compose_ai_stack

## Non goals for M0

- Authentication
- Billing
- Write operations
- Repository execution
- Team features
