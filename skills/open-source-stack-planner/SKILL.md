# Open Source Stack Planner

## Workflow

1. Understand business goal.
2. Identify technical constraints.
3. Select verified components.
4. Explain architecture.
5. Provide implementation steps and risks.

## Output

- Architecture
- Components
- Deployment approach
- Risks
- Alternatives
